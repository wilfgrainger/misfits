# Misfits 501 v1 Implementation Plan

> **Historical:** This plan records the original single-league implementation shape and is not the current release checklist. The current implementation plan is [`2026-08-20-white-label-leagues-v3.md`](2026-08-20-white-label-leagues-v3.md).

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the first production-ready Misfits 501 club darts league web application with public standings, Google-only player identity, result confirmation, and an admin portal.

**Architecture:** One Cloudflare Worker application serves a React + TypeScript SPA and a Hono API. D1 is the durable store; domain rules live in framework-independent TypeScript modules; Google OpenID Connect supplies identity while the application owns opaque sessions. Confirmed matches are the source of truth for standings, which are calculated rather than stored as mutable totals.

**Tech Stack:** React, TypeScript, Vite, Cloudflare Workers Static Assets, Hono, Cloudflare D1, Vitest 4.1+, `@cloudflare/vitest-pool-workers`, Testing Library, React Router, Zod, JOSE, GitHub Actions.

**Spec:** `docs/superpowers/specs/2026-08-19-misfits-501-v1-design.md`

## Global Constraints

- Target Cloudflare Free tier plus Google identity.
- One Cloudflare Worker deployable containing frontend static assets and Worker API.
- Google-only sign-in; no local username/password authentication and no password-reset path.
- Every player must choose a case-insensitively unique 3-24 character Misfits username before participating.
- Persist Google's stable `sub` plus an internal UUID; email is metadata, not the account key.
- Roles are exactly `PLAYER` and `ADMIN`; admin authorization is enforced server-side on every admin route.
- Result states are exactly `PENDING`, `CONFIRMED`, and `DISPUTED`.
- Only `CONFIRMED` matches affect standings.
- Standings order: points descending, leg difference descending, legs for descending, username ascending.
- Player-submitted results require the winner to reach the league `target_legs`; draws are invalid.
- Opaque session tokens are stored only as SHA-256 hashes in D1.
- Session cookie is `HttpOnly`, `Secure`, `SameSite=Lax`, path `/`.
- OAuth uses authorization-code flow and validates `state` before token exchange.
- State-changing APIs reject cross-origin requests and do not enable permissive CORS.
- D1 uses parameterized prepared statements.
- Privileged/result-changing admin operations append audit records.
- Suspended users cannot submit or confirm results.
- Closed leagues reject normal player submissions.
- Public views expose usernames and league data, never player email addresses.
- The supplied Misfits 501 artwork is the primary brand asset.
- Mobile-first, keyboard-operable, visible focus states, semantic forms/tables, WCAG AA text contrast, reduced-motion support.
- Do not add payments, teams, tournaments, handicaps, messaging, notifications, social profiles, or advanced statistics in v1.
